# Email-Validator

## About
A simple email validator built with HTML, CSS, and JavaScript. It checks if the email entered by the user is in a valid format, with real-time feedback.It uses an API to fetch validation details and displays the results dynamically.

## Features
- User-friendly UI with a clean and responsive design.

- Validates email addresses by checking format, domain, and deliverability.

- API integration for real-time validation results.

- Instant feedback with loading animation.

## Technologies Used

- HTML for structuring the webpage.

- CSS for styling and responsive design.

- JavaScript (Vanilla JS) for handling API requests and DOM manipulation.

- EmailValidation API to verify email authenticity.
